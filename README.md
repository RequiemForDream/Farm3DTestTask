Тестовое задание Farm 3D. Суть тестового, чтобы персонаж(фермер) мог сажать растения на поле 10 на 10.ОН должен перемещаться по полю с помощью NavMesh. Растение можно посадить, выполоть или собрать урожай через некоторое время, когда растение подрастет.
Есть общий Bootstrap для одной сцены. Не стал делать Game State Machine поскольку проект небольшой. 
Управление персонажем происходит через State Machine.
