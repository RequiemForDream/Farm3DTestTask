🌾 Farm 3D — тестовое задание

Небольшой прототип фермерской игры на Unity. Персонаж-фермер перемещается по полю 10×10 с помощью NavMesh, может сажать, пропалывать и собирать урожай с растений, которые растут со временем.

▶️ Видео-демонстрация: youtu.be/b3-WZ0ouHyY

✨ Основные фичи
Поле 10×10 клеток с системой координат/сетки
Навигация персонажа по NavMesh (Unity AI Navigation)
Жизненный цикл растения: посадка → рост (несколько стадий) → созревание → сбор
Взаимодействие через клик мышью / выбор клетки
Простая визуальная индикация стадии роста растения

🎮 Управление
ЛКМ по пустой клетке — посадить растение
ЛКМ по растению — собрать урожай (если созрело)

🛠️ Технологии
Unity 2021.3 LTS
Unity AI Navigation (NavMesh)
C#
